# Microsoft To Do Enhanced

تطبيق سطح مكتب لإدارة المهام، مبنيّ بـ WPF على .NET 10، يعمل **محليًا بالكامل** على جهازك بدون سيرفر وبدون SSMS.

## نظرة عامة

- واجهة XAML بأسلوب Fluent حديث مع تدعم كامل للعربية (RTL).
- قاعدة بيانات **SQLite** كملف واحد يُنشأ تلقائيًا عند أول تشغيل — لا LocalDB ولا SQL Server ولا أي اتصال شبكة.
- معمارية N-Tier (MVVM): منطق العرض / منطق الأعمال / الوصول للبيانات منفصلة.

## المزايا

- **المهام**: إنشاء وتعديل وحذف، خطوات فرعية، لوحة تفاصيل، أولوية (منخفضة/متوسطة/عالية)، تخصيص لون لكل مهمة، ترتيب بالسحب أو الأوامر، عدادات (الكل/اليوم/المهمة/المخطط).
- **العروض الذكية**: الكل، اليوم، المهمة، المخطط.
- **المهام المخططة**: تواريخ بداية ونهاية، تكرار (يومي/أسبوعي/شهري/سنوي) مع تجديد تلقائي للموعدها القادم (بما فيها نهايات الشهور).
- **المجموعات**: أعضاء وصلاحيات (مدير/عضو)، مهام مجموعات بسير عمل موافقة (معلّقة ← موافقة ← مكتملة)، تكليف المهام لأعضاء المجموعة، دردشة/منشورات مع تصفح.
- **المرفقات**: حتى 100MB لكل ملف مع عرض المقاس والصلاحيات.
- **الحساب**: تسجيل ودخول مع تشفير كلمات المرور (PBKDF2) وقفل تدريجي بعد المحاولات الخاطئة، تعديل الملف الشخصي (الاسم/البريد/اللون)، حذف الحساب بالكامل.
- **المظهر**: ثيمات داكن وفاتح مع لون مميز، حفظ التفضيلات محليًا.

## المتطلبات

- Windows 10/11.
- .NET 10 SDK (للبناء من المصدر) — أو Visual Studio يدعم .NET 10.

## التشغيل

من سطر الأوامر داخل مجلد المشروع:

```powershell
dotnet build MicrosoftToDoEnhanced.slnx
dotnet run --project MicrosoftToDoEnhanced\MicrosoftToDoEnhanced.csproj
```

أو افتح `MicrosoftToDoEnhanced.slnx` في Visual Studio وشغّل المشروع `MicrosoftToDoEnhanced`.

## قاعدة البيانات

- **المسار**: `%LOCALAPPDATA%\MicrosoftToDoEnhanced\todo.db` (تُنشأ تلقائيًا عند أول تشغيل).
- **بدون أدوات خارجية**: لا حاجة لـ SSMS أو أي عميل قواعد بيانات — كل شيء داخل التطبيق.
- **إعادة التهيئة** (حذف كل البيانات): أغلق التطبيق ثم احذف ملف `todo.db` (مع `todo.db-wal` و`todo.db-shm` إن وجدت) — سيُعاد إنشاؤها نظيفة في التشغيل التالي.
- **للمتقدمين/الاختبارات**: متغير البيئة `MICROSOFTTODOENHANCED_CONNECTIONSTRING` يتجاوز سلوك المسار الافتراضي، مثل:

```powershell
$env:MICROSOFTTODOENHANCED_CONNECTIONSTRING = 'Data Source=D:\Temp\test.db;Foreign Keys=True'
```

```
├── General/                          نماذج البيانات (Models)

│   ├── Data/
│   │   ├── SqlHelper.cs              تنفيذ الاستعلامات (Query/Execute/Transactions)
│   │   └── DatabaseProvisioner.cs    إنشاء/تهيئة قاعدة البيانات
│   ├── Repositories/
│   │   └── Repositories.cs           كل الاستعلامات المضمّنة (Users/Tasks/Groups/Planned/Attachments/Posts)
│   └── SQL/
│       └── CreateSqliteDatabase.sql   سكيمة القاعدة (12 جدول + فهارس + بذور)
└── MicrosoftToDoEnhanced/            تطبيق WPF (الواجهة)
    ├── Views/                        الشاشات (XAML)
    ├── ViewModels/                   منطق العرض (MVVM)
    ├── Services/                     خدمات الحوار
    ├── Themes/ Styles/               الثيمات (داكن/فاتح) والأنماط
    └── MainWindow.xaml(.cs)          النافذة الرئيسية + الاختصارات
```
